## 不得退化的要求

1. 已确定的品牌插画、Fin、字体、配色、页面丰富度和交互品质是持续验收标准，不得为了赶工降低。
2. 五个精品专题、五套财务工具、Discover、AI Copilot、My World 等后续重要页面，须达到现有核心页面同等或更高品质。
3. 不得以简陋通用卡片、纯文字长页面、占位插画或普通后台布局替代已经认可的内容与图形表达。
4. 每新增重要页面，须同时完成真实内容、适当插画/数据图形、可操作交互、响应式设计和视觉验收。不得先堆功能后草率补样式。
5. 每阶段提供真实桌面与手机截图，并对照认可图及实现基础。截图展示关键交互状态；不得用测试数量、组件数量或“视觉一致”的自评代替人工批准。
6. 明显视觉退化时不得自行宣布完成；记录差距，留在当前阶段修复。
7. 不得擅自替换已认可的 Fin、首页主视觉和设计系统。重大调整先说明范围和原因，并取得用户明确同意。

## 每阶段交付证据

- 真实桌面和手机截图；关键页面应包含初始、交互反馈及错误/空状态。
- 与认可目标及上个认可实现的并排对照，标明是否原画、示意图、真实模型结果。
- 页面内容、交互、响应式及可访问性检查，以及真实测试结果。
- 明确尚未实现项与视觉差距。最终是否通过由用户确认。

这些视觉规则不扩大任务范围。用户另已明确授权 Gate B 的 v3 本地阶段提交；仍禁止推送、服务器部署或对 main/v2 的改动。
