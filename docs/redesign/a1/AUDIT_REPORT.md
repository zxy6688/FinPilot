# FinPilot Gate A 审查结论（独立截图与源码检查）

**结论：Gate A 暂不通过——进入 Gate A1 定向返工；不批准 Gate B。**

## 正向进展
- 新首页在 1440×900 内已展示标题、问题入口和三条任务；旧 V3 的苍白知识星图已经移除。
- Decoder 有六节原创内容、事实/解释/未知分层和可操作通胀模拟，不再是只有几段话的阅读器。
- Money Lab 已有输入、后端储蓄计算、方案对比、Receipt 保存/恢复；新 16 项储蓄测试在审查环境中独立通过。
- Concept Studio 有三种 ETF/指数投资案例、针对性答案解释；Fin 有五表情和五姿态资产。
- 移动端有独立 CSS 布局和四入口底栏。

## 未通过原因（与已认可主参考图比较）
1. **主视觉美术差距很大**：参考图色彩鲜活、层叠插画、细致场景、Fin 主角有表情与体积感；Gate A 为简单扁平 SVG，背景浅淡，空间感弱。
2. **首屏三任务还是几乎同规格文字卡**：缺乏参考图里的实际内容缩略、图解和变化的信息层级。首页有功能，却未形成想探索的视觉吸引力。
3. **Fin 美术尚未达标**：角色已经从旧水滴变得可辨，但 3/4 侧面几乎还是正面；表情、动作的视觉差异小，缺少高质量细节和融合式场景表现。
4. **Money Lab、Concept Studio 的图解依然偏普通**：Money Lab 算法有用但像标准参数表+静态线图；Concept Studio 的图解是两张轴卡加装饰性柱图，缺少参考图强调的可探索感。
5. **手机首页卡片过长**：实际 390px 截图中三任务逐张堆叠，最末入口相对较深，Fin 与顶部角色出现重复。
6. **发现实质性路由错误**：Home `routeQuestion()` 对涉及“存钱＋购买力”的问题先匹配储蓄关键词，因此把购买力专题问题错误导向储蓄工具。
7. **核心视觉对照素材缺席**：Gate A ZIP 未包含 `02_APPROVED_RICH_DIRECTION.png`；`docs/redesign/DESIGN_AND_INTERACTION.md` 表示找不到明确认可的图片。这个问题必须先修，否则视觉交付缺少唯一标准。
