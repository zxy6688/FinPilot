## 0. 一句话任务、成功定义与不可妥协原则

**任务：把已认可的 FinPilot V3 视觉原型，扩展为“有内容、有工具、有互动、有个人记忆”的完整金融探索体验；让用户知道自己在做什么、为什么做、做完得到了什么以及下一步去哪里。**

Slogan：**看懂金融，形成自己的判断。**

全站的用户核心路径固定为：

**一个具体问题 → 对应的内容/工具/概念工作空间 → 实际操作 → 有依据的结果 → 保存到我的世界 → 能继续探索或恢复**。

产品真正的六个空间：`Discover / Decoder / Money Lab / Concept Studio / AI Copilot / My World`；其中 Decoder、Money Lab、Concept Studio 是三大核心任务工作空间。五个精品专题是贯穿这些空间的**内容旅程**，不是五个孤立的导航图标；五个财务工具是可复用的**计算能力**，不是五个封闭的小游戏。Home 是唯一统一入口。

**绝对不能出现**：做出 5+5 个页面，却没有内容关联；从首页跳进去不知道为何来到这里；点完实验没有解释、无法保存或无法返回；专题只是跳转到工具入口；My World 只显示数字，不会重新打开具体内容；伪实时新闻、伪 AI、伪学习成绩；旧 V3 卡片墙；牺牲 Fin、图解与排版换取开发速度。

本轮不追求更多一级菜单、无限加功能、真实行情实时更新、买卖投资决策、多智能体、复杂社交、重算法栈或全新架构。

**Gate B 的完成条件不是“所有按钮能点”**，而是完整用户旅程能够在同一网站内走通，内容解释有依据、工具计算正确、进度与结果可复用，而且任一页面都有明确的返回和后续操作。

## 2. 唯一明确的导航与层级（信息架构锁定）

### 2.1 桌面：仅五个一级标签

`首页 | 发现 | 财务工具 | 学概念 | 我的世界`；右侧另有 `全站搜索 | 问 Fin | 登录/账户`。

移动：顶部 `logo/搜索/Fin`；底部 `首页 | 发现 | 工具 | 我的` 四项；学概念始终可由首页第三入口、发现的专题、全局搜索和相关概念链接进入。不得隐藏到用户无法找到的深层菜单。

### 2.2 六个产品空间与一级导航的归属

| 用户看到的入口 | 层级与职责 | 禁止做成 |
|---|---|---|
| **首页 Home** | 总起点：品牌、问题输入、三大任务、精选专题、首页 Mini Lab、微练习、继续探索、Fin 小角落 | 全功能卡片目录、个人数据后台、空白展示页 |
| **发现 Discover** | 编辑式内容中心：五个精品专题 + 有来源的资料 + 金融解读室入口 | 复制首页卡片顺序的长列表、真假难辨的实时资讯 |
| **Decoder 解读室** | 发现下的具体解读工作空间/专题内部的解读章节，有证据/推论/图解/来源/实验 | 无来源的 AI 长文字、只有数十行摘要的空 Reader |
| **财务工具 Money Lab** | 五个工具的目录与独立工作台；专题中的计算可嵌入同一引擎 | 五张入口卡 + 五个重复的数字表单 |
| **学概念 Concept Studio** | 困惑问题、互动关系图、例子、即时判断、针对性反馈、进一步学习/复习 | 百科列表 + 选择题凑数 |
| **AI Copilot** | 全局“问 Fin”与上下文侧边助手；需要时进入完整对话页，保留同一会话 | 第二套 AI、假通用问答、伪造数据 |
| **我的世界 My World** | 真实发现手册：收藏、解读、实验小票、概念卡、阅读/路线续接、Fin 小角落 | 24 张 Evidence 百分比、金币成就墙、无法打开的收藏 |

**FinTalk 与旧 Learn/Lab/Topic/Review/Route**：先扫描真实路由；既有已工作的内容必须保持可达。FinTalk 作为相关主题的“讨论”次级入口；旧课程、路径及实验必要时从学概念、相关专题或我的世界进入；不悄悄删表、删路由、丢进度。旧公开入口如需迁移，提供有意义的重定向或兼容页面，而非空白/404。

### 2.3 目标路由语义（路径字符串可适应现有 React Router，不必全盘改名）

- `/`：Home
- `/discover`：专题索引与资料入口
- `/discover/{storyId}` 或现有对应专题路径：专题故事完整阅读/互动
- `/decoder/{contentId}`：以来源与解释为中心的金融解读页面
- `/money-lab`：五工具目录；`/money-lab/{toolId}`：具体工具工作台
- `/concept-studio`：概念探索；`/concept-studio/{conceptId}`：单主题交互
- `/my-world`（可兼容旧 `/profile`）：Notebook 入口及进度；`/my-world/{artifactType}/{artifactId}`：真实记录恢复或详情
- `/copilot`：AI 会话页；上下文侧边栏与它使用同一会话 ID

**先列实现中的真实路径，再写适配表。上方是语义约束，不要求无谓更名导致已有深链接失效。**

### 2.4 页面通用结构：用户必须随时知道“我在哪、在做什么、下一步是什么”

所有二级详情页显示自然语言页面定位 + 回到上层的 Breadcrumb（例如 `发现 › 预算专题`；`财务工具 › 储蓄规划`；`学概念 › ETF 与指数基金`）。首屏只出现**一个主要行动**：开始阅读/计算/互动；保存是次要行为，深度追问/分享收纳在次级操作中。

每个详情页必须有：
- **起点/问题**：一句“今天要弄清什么”；适用人群和预计时间（仅在有依据时）；
- **当前行动**：编辑阅读、调参、图解推演或判断；
- **即时结果**：数字/图表/解释/反馈就在当前位置；
- **来源与边界**：事实出处、假设和不确定性；
- **成果与下一个动作**：保存、重新打开、学相关概念、试相关工具、返回专题/目录。

不能把“继续探索”统一塞成推荐卡片海。每一页最多显示 1 个首要下一步 + 1–2 个语义相关备选；推荐理由用普通话说明（如“这里刚刚用到了实际购买力的概念”）。

## 3. 用户任务地图与跨页面流（这是核心验收，不是附加功能）

### 3.1 新用户：问题驱动，而非漫无目的点击

`首页：看懂金融 + 我可以问什么` → 输入问题或选一条明确示例 → **导航选择/精确匹配** → 到正确工作空间 → 做一次有结果的操作 → 保存第一张发现卡 → 我的世界能找到并重新打开。无需先填写兴趣问卷，无记录时没有虚假进度。

首页问题入口**是“寻找相关探索内容”**，不是万能 AI。只有明确唯一匹配已存在内容时直达；多主题/不确定时给三类真实可用的路径选择，保留原问题，并让用户自行决定。若用户明确选择“问 Fin”且真实 AI 可用，带原问题进入相同 Copilot 会话；Demo 时明确能力边界。保留 A1-P0 的正确分流测试。

### 3.2 资讯用户：一件事 → 概念 → 模型 → 我的发现

`发现：有来源的精选专题` → `Decoder：先说结论和证据` → 展开关键概念与因果图 → **在正文旁直接打开相关 Mini Lab**（不是跳走丢阅读位置）→ 比较结果 → 记录“一句话发现” → Notebook 收录来源、图表参数与原文入口。还可从文章中的术语进入 Concept Studio，返回时恢复原阅读位置。

### 3.3 计算用户：一个数字问题 → 变量 → 解释 → 方案比较 → 小票

`首页/工具目录/专题` → `Money Lab`，初始参数预填且可修改 → 立即显示计算与趋势 → 切换/固定方案 A/B → 用普通语言解释**什么条件造成差异** → 保存 Money Receipt → Notebook 重新进入并恢复全部关键参数（包括利率口径、期初/期末、期限等）。关联专题解释“这个计算能回答什么，不能回答什么”。

### 3.4 学习用户：困惑 → 图解 → 尝试 → 反馈 → 复习

`首页/相关术语/学概念` → `Concept Studio：一句困惑` → 操作图解与案例 → 选一个判断 → 即时给出基于正确知识的原因、错误选项为何错误 → 有意义的继续演练 → 保存概念卡并记录适当的复习材料 → My World 可重新练习。一次错误不贴“稳定误解”标签。

### 3.5 回访用户：有真实记录才出现继续

`首页：继续上次探索`（最多 2 条真实高价值活动）或 `My World` → 打开之前未读完的文章/未完成路线/保存的小票/值得复习的概念 → **恢复原对象、位置或参数** → 继续操作 → 新结果在时间上与原记录可区分。没有记录时显示“先试一个 2 分钟的工具/专题”，不制造历史进度。

### 3.6 五个专题各自的固定闭环（必要时嵌入工具，不制造多次无意义跳转）

| 专题 | 核心困惑与故事 | 必须进行的真实行动 | 完成后保存 | 正确的下一步 |
|---|---|---|---|---|
| **大学生的第一份预算** | 我的生活费为何月底不够？固定/可调/偶发支出 | 填入收入、支出，模拟餐饮上升/突发开销，观察结余与预算构成 | 预算快照 + 用户发现 | 预算工具复盘 / 应急准备概念 |
| **存钱不等于购买力不变** | 同样金额为何买到的东西可能变少？ | 调节通胀、期限、名义增值条件，比较购买力 | 参数 + 结果 + 来源 + 实际收益理解 | 通胀工具 / 名义与实际概念 |
| **从一次降息读懂债券** | 为什么政策降息不保证债券上涨？ | 区分政策/市场收益率/预期，调债券市场收益率看价格 | 教学假设、债券价格实验结果、判断 | 债券价格概念 / 相关阅读 |
| **ETF 究竟是什么** | ETF 与指数基金是不是同一个东西？ | 切换不同基金情景，在“交易结构×投资策略”二维图中定位，完成判断 | 概念卡 + 练习反馈 | 费用/跟踪误差概念 / 复习 |
| **一笔贷款到底还多少** | 利率低是否意味着总成本低？ | 输入本金、期限、费率与费用，切换方案比较现金流和总费用 | 贷款成本模型输入和两方案对比 | 贷款工具复算 / 费率概念 |

专题首页需清楚标明“这是一个有内容、有互动、有可保存结果的故事”，**不把专题当作工具目录的别名**。

## 4. Home 的完整布局与操作，不得简化

设计已经锁定为「晴日编辑室 75% + 微光探索世界 25%」。仍以 `02_APPROVED_RICH_DIRECTION.png` 为终极丰富度参照，以实际 A1-P0 为可运行基线；**增强内页和内容，不能损坏现有品牌 Hero 与 Fin**。

桌面首屏 1440×900 左主标题/问题框 + 右 Fin 金融探索桌，紧接三个外形不同、内容有真实预览的任务入口。五个导航标签，无多余平级入口。首屏就看得到“可以做什么”，绝不出现 V3 那种淡星图大留白。

**第二屏及其后必须按以下语义层次呈现（允许视觉错落，不允许逻辑乱序）：**

1. **编辑精选 / 一条真实好专题**：一大两小，五篇完整故事在 Discover 都可找到。卡片露出真实主题、具体收获、历史/教学来源标记和阅读时间估计；不是贴一张通用插画。
2. **今天可以试试 / Mini Lab**：可以在 Home 直接调整一项真实参数并更新数值/小趋势图；操作“打开完整工具”需传递对应参数；旁边最多两个不同工具快捷入口。
3. **一分钟弄懂 / Concept Preview**：一幅具体概念关系图 + 一个真正可回答的微练习，答完解释，并能进入相同概念的完整页面。
4. **继续我的探索**：仅真实有历史才展示（最多 2 条）阅读续接、未完成路线、实验小票或复习；新用户呈现具体推荐起点，不展示 0% 统计板。
5. **Fin 小角落 / 发现手册**：显示最近真实保存的 1–2 件物品及可点开入口。Fin 可互动但不拦内容。
6. Footer：教育用途、资料方法、隐私、关于。

**Home 入口-落点合同：**
- “看懂一件事” → Discover/精选解读（能进入 Decoder）；不得到空新闻目录。
- “算清一个问题” → Money Lab 的工具目录（若点击具体试算，直达该工具，参数带入）。
- “弄懂一个概念” → Concept Studio 的主题选择或指定概念。
- 编辑故事卡 → 其对应专题**完整页**。
- 小工具 → 真实完整计算页，带当前参数，不无故重置。
- 概念微练习 → 同一概念详情，保留合理的尝试状态。
- 保存成果 → My World Notebook 的相应真实条目（未登录则明确访客限制）。
- 问 Fin → Copilot，会话及 context 与当前页面一致。

首页如有“进度百分比”“本周已学”等数字，必须对应当前用户真实学习证据，不能用演示假数据伪装成用户记录。

**Mobile**：顶部标题/Fin 不重叠，提问框首屏内，任务入口为带真实预览的精致竖向条目；精选专题横向滑动或大中搭配，工具操作显示最重要数字；底部导航不挡输入/保存。必须验证 375/390/430/768px。

## 5. Discover：编辑式内容中心（不是 Home 的重复）

信息层级：
1. 顶部一个主专题/重点问题：例如“存钱为什么不等于购买力不变”，说明为什么值得理解；
2. 五个精品专题的**目录与明确分类**（钱与生活 / 市场与投资 / 借贷）；每篇露出关键问题、预期学到的东西、互动类型、来源类型、有效时点、可继续状态；
3. “从现实信息开始”精选官方/可靠来源资讯或解释性资料（与站内原创编辑解读明确区分），允许按主题检索过滤，不伪装实时新闻；
4. “按问题探索”主题入口：例如储蓄、通胀、利率、债券、ETF、贷款；
5. 与所选内容相关的讨论入口（如现有 FinTalk 内容真的有对应主题）。

首页只负责引发兴趣；Discover 负责**筛选、判断内容是什么、挑一篇认真看**。不要把 Home 上所有卡片原样复制一遍。

分类维度清楚区分 `原创互动专题 / 编辑解释 / 外部来源资料 / 教学假设案例`。只允许内容库真实存在的筛选结果；空结果给有用的返回与建议，不假造文章。

## 6. Decoder：一份有依据的可交互解释，不是泛泛 AI 回答

详情页基本段落顺序（可结合主题调整，但不得缺核心环节）：

1. **问题型标题 + 一句话结论 + 资料属性**：原创专题/历史案例/来源资料/教学假设。来源标题、日期、机构及跳转链接有则显示，缺少则明确标明，不得补造。
2. **What we know / 事实与证据**：有来源的可查信息与引用指向；用户粘贴文本应标记“用户提供，未独立核实”。
3. **What it means / 机制图解**：区别事实、教育性解释和假设推演；最多先突出 3–4 个关键概念，可展开进一步定义。
4. **What it does NOT mean / 不可推出什么**：例如“降息不等于任意债券必涨”；反例、边界和不确定性。
5. **Try it / 实际动手**：嵌入复用的通胀、债券、预算等一个小型模型；输入改变，数字/趋势与解释同步；可展开独立 Money Lab 并带入参数。
6. **Check / 一个有意义的理解检查**：短题/判断，正确与错误均有针对性说明；不以答完等于掌握。
7. **Sources & Methods / 来源方法**：权威资料、口径、更新时间、编辑性处理说明；未核实信息标明。
8. **My takeaway / 保存一条发现**：允许用户写一句理解，存成带来源、相关话题、模型输入的 Notebook 记录；完成后实际可以找到并恢复。
9. **Next**：最多两条真正相关的深挖入口（例如购买力 → 名义实际概念 / 通胀计算器）。

桌面阅读列 720–780px，目录/术语/来源采用适当侧栏；手机单列，将侧栏改为可展开的来源/术语模块；正文高对比、配图内容有实际解释价值。不能再只有 130–180 字的三个简述段落；但也不要为了字数灌水。每篇至少能支撑一次完整、独立、可回顾的理解过程。

**自由粘贴/问问题**：仅当真实外部模型可用且授权时执行模型分析；Demo 只能匹配现有专题、解释已知概念或显示能力边界，不可编造对任意文本的事实核验。外部报道不可整篇抓取转载。

## 7. Money Lab：五个认真制作的财务工作台

### 7.1 统一操作逻辑（必须一致）

工作台首屏：**你想算清什么？** → 默认合理、明确标注的示例参数 → 左侧可修改变量 → 右侧高质量结果主图与关键数值；手机先看到最重要结果，再展开参数和图表细节。下方依次：假设说明 → 固定 A/对比 B → 理解差异 → 保存 Money Receipt → 关联专题。

工具卡片不是入口介绍：一进入就可试算，不必填写十个必填框；每个工具都能通过改变关键变量得到及时且可解释的响应。

每个工具必有：输入校验、合理范围、键盘数值输入+辅助 slider、确定性后端计算、关键结果、至少一种与问题相称的可视化、A/B 对比（明确两个情景分别是什么）、说明差异由哪些条件驱动、保存并恢复**模型输入口径与结果快照**、空值/0/极值/错误状态、教育声明与模型边界。

### 7.2 五个工具的计算契约

**① 储蓄目标规划**
- 输入：目标金额、已存本金、定期储蓄额、期数、收益率与折算口径、月初/月底存入；可选择“固定月存求终值 / 固定目标反推月存”。
- 结果：累计本金、假设增值、期末总额、距离目标的差额、逐期轨迹、目标覆盖进度。
- 数学：`FV = P0(1+i)^n + PMT * ((1+i)^n - 1)/i`（**月末**，`i≠0`）；月初定期存入的 PMT 项再乘 `(1+i)`；`i=0` 时 `FV=P0+n·PMT`。明确年有效收益率换算 `i=(1+r_eff)^(1/12)-1` 或名义年率折算，不得混用。
- 测试：0%/期初期末差异/已存金额/反推目标/无穷或负输入。

**② 复利与时间价值**
- 输入：现值或初始投入、时间、假设年利率与计息频率、是否额外定期存入（若支持，区分现金流时间点）。
- 结果：终值、利息构成、不同开始时间或计息频率的情景比较，图表说明时间效应。
- 数学：`FV = PV(1+r_nom/m)^(m·t)` 仅在名义年率、每年复利 m 次口径下成立；有效年率使用 `(1+r_eff)^t`。用户必须知道所选输入是哪种口径。
- 不能用高收益预设暗示真实收益承诺。

**③ 通胀与购买力**
- 输入：当前或未来名义金额、年通胀假设、年数；可增加名义增值率作为对照。
- 结果：未来相对于今天的购买力、金额与购买力两条曲线、真实（扣除通胀）增长对比。
- 数学：`real purchasing power = future nominal amount/(1+inflation)^years`；名义增长率与通胀率同时存在时 `real rate = (1+r_nominal)/(1+inflation)-1`。区分购买力衰减与收入未来实际价值，不混用基期。
- 非实时通胀假设不得冒充统计发布数据。

**④ 贷款实际成本**
- 输入：贷款本金、期限、还款方式、利率口径、放款/还款时间点、一次性或周期性费用，至少支持标准等额本息、等额本金比较（若项目资料支持）。
- 结果：每期还款、总利息、总费用、总支付、剩余本金与逐期现金流；A/B 对照含真实费用。
- 数学：标准月利率 `i`、期数 `n`、本金 `P`：等额本息月供 `P*i/[1-(1+i)^(-n)]`，`i=0` 则 `P/n`；等额本金每期本金 `P/n` 加剩余本金乘当期利率。若展示“综合年化成本”，应基于明确的净到账与还款/费用现金流求解等效利率并说明约定；未严格按对应法律/地区监管标准计算，不可随意标作 APR/监管真实年利率。
- 边界：零利率、费用为零、期限异常、费用超过合理边界、负现金流与数值求解失败。

**⑤ 个人预算情景比较**
- 输入：收入、固定/可调整支出、储蓄目标、一次性支出，可增加当月变化情景。
- 结果：收入支出结余、现金流分类图、目标缺口、极端情景对结余影响、可调整变量的敏感性。
- 不强推“50/30/20”作为唯一正确规则；不同生活状况可能不同，模型展示选择与约束。
- 测试：零收入、超支、负结余、偶发费用、金额边界与类别重复。

**债券定价的小实验**：保留作为“降息专题”的嵌入式模型，不必强行变成第六个顶级财务工具。可使用明确的固定现金流贴现，写明教学假设、剩余期限和价格/收益率反向关系；政策利率与市场收益率不视为同一变量。

### 7.3 Money Receipt 不是图片装饰

保存项至少包含：所属用户/访客分区、工具类型、参数与口径、模型版本、结果摘要、A/B 情景、保存时间、用户命名/备注（可选）。Notebook 点击后能进入真实对应工具、恢复当时的参数，允许在原记录基础上“再试一个情景”，不能悄悄覆盖原记录。导出/分享仅在有实际实现且不泄露私人数据时呈现。

## 8. Concept Studio：从困惑到理解的完整交互

页内结构：**一句困惑 → 一张可操作关系图 → 两个生活化例子 → 1 次简短判断 → 解释选择理由 → 尝试第二种情境 → 保存概念卡 / 相关专题**。

首批优先围绕五个专题的关键概念：名义/实际、政策利率/市场收益率、债券价格/收益率、ETF/指数基金、贷款利率/总成本、固定/弹性支出。

已有 ETF 二维分类矩阵不得退化：`是否 ETF（交易结构） × 是否跟踪指数（投资策略）` 的关系必须正确，主动 ETF 与非交易所指数基金等案例要能解释。其他概念应依其本质设计不同图解（购买力双曲线、债券贴现、贷款现金流），**不能所有概念都套同一个四宫格**。

答错时高亮具体误区并展示反例，而不是只弹“再试一次”；正确时解释原因。一次错误不推断用户永久不会；有真实存储和正确事件时才写 Review/Misconception。概念卡在 Notebook 中可重新打开图解和历史练习，不只是标签。

已有 V2/V3 的学习路线和复习逻辑必须**保留且可从“学概念/我的世界”找到**；Gate B 不要求额外发明更复杂算法，深层个性化留 Gate C。

## 9. My World：结果在这里留下来，形成再次打开网站的理由

不是抽象 Evidence 仪表盘，而是编辑式个人探索手册。页面组织固定为：

1. **最近的发现（最近 1–3 件真实记录）**：有缩略图/工具结果可见；一眼知道这是什么、何时做过。
2. **我的收藏**：筛选 `金融解读 / 实验小票 / 概念卡 / 专题进度 / 课程与学习路线`；如果类型暂无记录，提供对应真入口。
3. **继续探索**：确有阅读续读、未完成专题/路线、到期复习才出现，直达上次位置。
4. **Fin 的小角落**：已认可角色，真实收藏和小纪念物对应具体保存事件，可点击回溯；禁用随机金币徽章。
5. **我的知识关联（次级折叠/标签页）**：可复用已有图谱和证据状态，但不要把全屏铺成 Topic 百分比卡。

**保存规则必须清晰：**
- 登录用户：写入有归属校验的后端持久化数据，刷新与新设备重新登录可读取；不得只用 localStorage 然后宣称账号同步。
- 未登录试用：可以体验工具和有清楚提示的浏览器本地草稿/试用记录；不能伪造云端保存成功。登录时是否导入访客记录，需明确说明和经用户触发，不能自动覆盖。
- 保存反馈：按钮状态、成功/失败消息要与服务器响应一致；失败可重试且保留未提交输入。相同动作避免重复建多条记录。
- 用户 A 不能访问用户 B 的 Notebook ID；后端校验 owner，不仅在前端过滤。
- 保存后点击某条记录能重进原文/原模型/原概念且恢复正确状态；模型版本改变需明确旧记录计算的版本与是否重算。

**成果的数据最小合同**：`type + source_id/tool_id/topic_id + stable_id + user_id/guest scope + created_at + inputs/position + computed result summary + assumptions/model version + optional note + source attribution`。以现有后端模型优先兼容实现，严禁为凑接口无谓复制多份同样业务表。

## 10. AI Copilot 与 Fin：有用、克制、守住能力边界

Fin 形象**冻结**：奶油白主体、青绿罗盘冠、湖蓝鳍翼、深青眼睛、阳光黄罗盘吊坠；延续 A1 原画、三视/表情/动作。不要用 emoji、临时 SVG 或别的 IP 替换。

Fin 是 Copilot 的视觉伙伴，不是第二套模型。统一行为：
- 点击 Fin 或“问 Fin”打开可键盘操作的抽屉：`问 Fin 一个问题 / 看看我的发现 / 安静一会儿`；
- 在 Decoder 选中术语/段落可带 `内容 id/本段术语/用户具体问题` 询问；在 Money Lab 带 `工具/当前参数/模型输出摘要`；在 Concept Studio 带 `概念/案例/用户误解点`；
- 从侧栏点击“在 Copilot 中继续”应保持同一个对话 session 和上下文，不重新开聊；
- AI 用于解释/举例/比较/引导，**不能成为数学结果唯一来源，不能自行声称核实外部事实**；
- Demo mode 只有确定覆盖的案例/模板能力，未知问题应诚实提示，不可假装万能模型。

Gate B 应保障已存在会话连续性不回归、三个新空间能正确提供上下文结构或在无外部模型时给明确降级；**真正复杂的多轮个性化、外部来源抓取、多模态或长期 AI 学习代理属于 Gate C/未来**，不因此阻塞五个专题和工具交付。

Fin 的反馈只在真实有意义的动作后出现：保存小票递小票、保存概念卡贴进手册、续读提示、必要时安静；支持 reduced-motion。重大反馈频率限制，不遮挡图表和手机按钮。

## 11. 五个精品专题的“内容质量合同”

五篇必须是**完整原创编辑式互动专题**，各自具有独立的叙事线索、具体情境、清楚的问题、实质解释、数据/图解、互动、模型边界、1 道理解检查、参考资料、保存发现和下一步。拒绝统一“三段解释 + 计算器链接 + 完成”的量产模板。

每篇至少应包含若干有信息含量的章节，足以完整回答核心困惑；段落长度由解释需要决定，不以凑字数代替质量。嵌入图解需要能说明机制，不是装饰曲线；每个来源要能追溯到标题/机构/原始地址/日期（若有），不能编造。

详细专题内容结构：

**A. 大学生的第一份预算**：一个明确标注为模拟的大学生月度案例；固定、弹性、偶发与应急的解释；支出分类及结余/储备；根据输入真实绘制比例；“餐饮上涨”“突然需要买教材/维修”作为参数场景；对比结果解释；如何看待现实限制（助学金、生活费不稳定等）；保存预算小票。避免对大学生个人消费作道德评判。

**B. 存钱与购买力**：同额不等价的直观例子；名义金额、通胀、购买力之间的区别；可调整通胀/年限/名义增值；解释模型不是预测未来物价；考虑通胀/利息的示例情景；来源、误区与复盘。复用已有购买力六节编辑稿，避免重复写两个矛盾版本。

**C. 降息与债券**：政策利率/市场收益率/债券价格三层关系；市场提前预期、风险溢价、期限敏感性等解释到初学者可理解的程度；基于可核查的历史政策材料或明确假设，不能伪装今日新闻；固定票息债券模型；调贴现收益率观察价格，理解“政策降息不能保证所有债券上涨”。

**D. ETF 是什么**：基金是什么、ETF 是何种交易结构、指数投资是一种什么策略；交集图与主流例子、主动 ETF、非交易所指数基金；流动性、价格偏离、管理费/费用和风险的入门说明，不能误导“ETF = 保本”；结合已有二维矩阵和多情境判断；保存卡片。

**E. 贷款总成本**：名义利率与费用区分，等额本金/等额本息现金流图、期限对月供/总利息的影响、提前还款/罚金若模型支持应说明约束（不支持不假装有）、清楚的两方案对比与“看总成本而不只看单月还款”的结论；不推荐贷款产品。

资料时效性：所有外部案例标注时间属性，特别是利率政策事件；不能将静态资料称作“今日热点”。有事实有出处，模型有假设，用户粘贴内容有未经核实标记。尊重第三方文章版权，不大段复制。

## 14. 技术、持久化、内容与安全工程边界

- 继续 React/TS/Vite + Python/FastAPI/SQLAlchemy/SQLite 既有栈。避免与任务无关的重架构、大型图谱依赖和复杂新基础设施。
- 建立共用内容/关系模型：`story_id, topic_ids, source_type, source_title/url/date, explainer blocks, illustration/diagram refs, embedded_tool_id, concept_ids, learning_check ids, related next actions`；真实项目有相应结构时直接复用，不要求逐字建字段。
- 各工具统一后端权威计算接口、输入参数类型、错误码、模型口径与版本；图表渲染真实 API 输出而非前端固定常量。前端可乐观展示编辑状态，但成功保存只能确认服务端已接受。
- 登录用户的阅读、Notebook、实验、概念卡、练习归属于 account，支持刷新恢复/新会话读取。访客可以试用并知道局限；不泄露一人的记录给另一人。
- 持久化兼容 V1/V2/V3 现存表和 seed；若需迁移必须可重复、非破坏并有迁移前后测试，不丢旧 Lesson、Topic、FinTalk、Route/Review 记录。
- 存储与 UI 要能区分 `草稿 / 已保存 / 保存失败 / 游客仅本地`。提供失败重试、键盘和网络中断处理。
- 搜索和首页分流只索引**实际存在且可打开的**故事、工具、概念、已有内容；不创建虚假的来源卡与空结果。
- 安全：API Key 服务端保管、输入长度限制、越权访问测试、输出正文转义、无敏感数据提交、非真实市场数据明示。
- 性能：懒加载非首屏插画、避免一次请求全部五专题全文；图表移动端平稳、支持 reduced-motion、避免闪烁/跳动。

## 15. 视觉锁定与“丰富但不乱”的具体验收

**已锁定**：Home A1-P0 主视觉、Fin 形象/三视表情、品牌色/字体/信息密度；最终目标 `02_APPROVED_RICH_DIRECTION.png` 的成熟丰富度。任何功能增量不得导致这些区域退化。

全站六空间应有**有区别但同品牌**的视觉个性：
- **Discover**：数字杂志：主封面、专题大小错落、题材封面、出处/类型和明确的阅读预期；
- **Decoder**：互动长文：有高质量图解、有结构的正文、来源与事实分层、深度交互嵌入阅读；
- **Money Lab**：财务工作台：占主视觉的曲线/现金流图与结果、高效输入区、左右对照、可阅读小票；
- **Concept Studio**：概念课堂：不同的知识结构图、可试例子、针对性反馈，不全是重复问答卡；
- **AI Copilot**：安静但智能的上下文工具，回答清楚、状态清楚、不占据主屏；
- **My World**：温暖的个人收藏书房，视觉展示真实记录/纸片/票据/书签，而非后台 KPI。

**内容布局规则：** 每页一个视觉主角，最多一个强 CTA；二级信息经层次/Tab/渐进展开呈现；可见任务入口不超过用户能一次理解的范围。首页丰富 ≠ 每个模块都挤成同等大小卡片；主工作空间丰富 ≠ 十几个按钮同时出现。图表、插画、文字各有自己的信息责任。

严格比较：1440×900 桌面首页与工具页面、375/390/430/768 手机；新用户/回访用户；数据多/空；输入前/修改中/保存后/错误态。字体不小得读不清，颜色对比合格；不遮挡、无横向滚动、弹层可键盘访问；不能用用户看不到的截图替代运行网站。

**每一个新增主要页面必须同时交付**：真实数据/真实教学内容 → 交互实现 → 原创适配图解/插画 → 桌面截图 → 手机截图 → 点击路径与回退 → 保存验证。完成一个差一个，不留到 B5 集中补丑 UI。

## 16. 可客观验收的 E2E 用例（必须真实浏览器走通）

必须至少包含以下体验流程，除 unit tests 外用真实 UI 自动化或人工录屏/截图步骤验证：

1. **新访客首次探索**：Home 输入 ETF 问题 → Concept Studio 对应概念 → 操作二维分类 → 答错获得真正解释 → 答对 → 保存概念卡（游客明确仅本地）→ My World 再打开该概念。
2. **购买力长文**：Discover 选“存钱与购买力” → Decoder 看到来源/解释/互动 → 修改通胀与期限 → 从正文进入完整工具并保留参数 → 返回专题阅读位置 → 保存理解 → Notebook 再打开。
3. **预算真实闭环**：Home 选预算专题 → 改月收入/固定/弹性/偶发支出 → 添加突发事件 → 图与结余真实变 → 比较方案 → 登录保存 → 刷新/重新登录 → My World 仍能恢复原参数与模型结果。
4. **贷款与费用**：Loan 工具 0% 与有费率、有一次性费用模型对比 → 两方案总成本和现金流正确 → 保存小票 → 再打开复算一致。
5. **储蓄/复利精确性**：Mini Lab 输入月存额/期限 → 进入完整版带参数 → 固定 A、调整 B → 一键恢复 A → 保存 Receipt 并校验数据；独立公式核对。
6. **降息债券概念**：从 Discover 历史/教学案例出发 → 把政策利率和债券市场收益率区分 → 调整市场收益率 → 价格变化符合理性模型 → 检查题答对/答错反馈 → 来源可打开。
7. **移动全链路**：390px 完成一次从问题入口到完整工具再到保存的过程；同时检查 375/430/768 标题、Fin、图表、导航及键盘输入不遮挡。
8. **用户隔离与失败态**：不同账号访问同 ID 记录被拒绝；离线/保存失败时 UI 不显示“已云端保存”；重试能恢复输入。
9. **导航与旧链接**：主页所有 CTA、五主导航、搜索结果、旧 V1/V2/V3 入口没有空页、误导性落点、循环跳转与死链。
10. **AI 能力边界**：无外部 Key 时 Demo 不编造来源、对陌生问题提供已支持内容的引导；Context AI → Copilot 会话连续性不得回归。

**每一步要交付“入口 → 动作 → 输出 → 保存/返回”的具体证据**，不是只说“浏览器跑通”。
