## 手机验证

真实Chromium浏览器375/390/430/768px检查15核心页面的横向溢出、图片加载和可见内容，另生成17页面390px首屏供审查。首页375/390/430px标题29px、768px为36px；没有缩小至难读字体或隐藏Fin来避开遮挡。截图见 final-home-first-*.png 与 routing/screenshots/home-*.png。

390px已走通首页问题→预算专题→改收入→突发支出→工具→账户保存→手册恢复。桌面浏览器模拟视口不等于真机软键盘测试；本轮未连接物理iOS/Android设备，不宣称完成真机键盘或Safari专项验收。
