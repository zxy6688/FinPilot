## A. 给 Codex 的最高优先级指令

你负责 **FinPilot v3 Redesign**。用户已明确否决原 V3 的页面和体验。请将 `v3` 作为替换版的目标分支，**不要命名或创建 V4**。你的目标不是为旧版换 CSS，而是将它改造为**内容丰富、工具实用、交互深入、具有个人记忆与 Fin 陪伴的金融探索平台**。

### A1. 不得遗漏的范围

本次设计含 **六个产品空间**，其中三个主工作空间要足够深入：

1. **Discover 发现**：编辑精选、现实金融信息、可信来源、五个专题故事、进入解读室；像数字杂志，而不是空新闻列表。
2. **Decoder 金融解读室**：有来源的真实内容、事实/解释/不确定性区分、事件脉络、专业术语与因果图解、嵌入式计算、追问、保存发现；不伪造时效性或事实核验。
3. **Money Lab 财务实验室**：储蓄目标、复利与时间、通胀购买力、贷款成本、个人预算五个首发工具；真实数学校验、变量调整、多情景比较、动画图表、保存可恢复的 Money Receipt。
4. **Concept Studio 概念工作室**：可操作图解、案例、概念对照、错误针对性反馈、短测验、学习路线、复习；真实互动优先于长段百科文。
5. **AI Copilot 智能助手**：从阅读、实验与概念场景带上下文展开追问，沿用已有会话；无真实模型时严格标示 Demo 能力，不冒充任意文本智能分析。
6. **My World 我的世界**：个人发现手册，包括保存的解读、实验小票、概念卡、笔记、未完成学习、必要的复习，以及 Fin 的收藏与小角落；不要展示 24 张百分比墙。

**注意：六个产品空间 ≠ 六个一级导航。** 桌面导航固定为：`首页 / 发现 / 财务工具 / 学概念 / 我的世界`；`问 Fin` 为上下文 AI 入口。`Decoder` 在发现的内容详情和输入流中；`FinTalk` 若保留，仅作为相关话题讨论的次级入口，不要删除现有数据。

### A2. 五个精品专题必须是“内容+工具+学习”的真体验

必须覆盖且优先做深以下五项：

- **大学生的第一份预算**：固定/弹性支出和应急储备 → 录入预算 → 情景变化 → 预算实验小票。
- **存钱为什么不等于购买力不变**：名义/实际价值 → 通胀购买力交互 → 比较假设 → 发现记录。
- **从一次降息读懂债券**：政策利率、市场收益率、预期 → 教学案例 → 债券定价小实验 → 结论的适用边界。
- **ETF 究竟是什么**：ETF 的交易结构与指数跟踪策略区分 → 对照图解 → 即时判断 → 错误解释。
- **一笔贷款到底要还多少钱**：年化利率口径、期限、支付时点及附加费用 → 真实还款模型 → 总成本对比。

每个专题必须有：**原创实质性内容、示例事实/来源标记、至少一个可操作组件、明确学习结果、保存或继续机制**。拒绝“只有 100–200 字的三个短段落 + 一个完成按钮”；正文、解释、图解和计算应配得上阅读界面。不可复制第三方版权文章全文。必须区分当期资料、历史案例和纯教学示例。

### A3. 首页具体应当丰富到什么程度

首页在 1440×900 桌面首屏应有：漂亮但不过大的品牌 Hero、清晰高对比的中文标题、突出的问题入口、右侧精致的 **Fin 金融探索桌**插画、三大真实功能入口且可见。再向下应有：

1. **编辑精选**：一大两小的五个专题故事入口，真正可阅读/互动；
2. **工具速达**：一项在首页即可调节参数并即时计算的 Mini Lab + 至少两个完整工具入口；
3. **一分钟弄懂**：一个可以交互的 Concept 图解/迷你练习，而非文字宣传；
4. **继续探索**：仅有真实记录时出现之前的解读、实验、课程、路线、待复习内容；首次访问展示有价值的引导，不出现零百分比空面板；
5. **发现手册与 Fin**：可查看真正保存的卡片/实验收据，Fin 只做适量陪伴。

页面采用**错落有序、大小不同的编辑式布局**，真实图表、插画和内容形成丰富度。不要改成：空白大 Hero、苍白星图、三个同规格空卡片、大片泛泛品牌文案。内容和实用功能优先，辅助 Fin 插画；比例感大致为功能内容 60%、品牌视觉插画 25%、Fin 趣味 15%，不是硬性像素计算。

### A4. 视觉硬约束

- **晴日编辑室（约 75%）+ 微光探索世界（约 25%）**。清新、亲和、有插画、有内容层次，但不幼稚、不过度炫彩，不是投顾交易终端。
- 基础色：`#F6F9F5` 浅背景、`#FFFFFF` 表面、`#243D40` 文本、`#267B78` 品牌青绿、`#79BDCC` 湖蓝、`#F1C467` 阳光黄、`#EFA79B` 少量珊瑚粉；按用途分配，避免全页面彩虹渐变。
- **中文统一现代无衬线**，强调字形清晰、字重足够；英数 Inter 或配套无衬线。**禁止旧 V3 混杂 Georgia 英文字体、密集极小全大写英文、颜色过淡的辅助标签**。
- 不要用 Card Wall 替代排版，也不要用留白替代内容。桌面、移动端要分别设计；375/390/430/768px 核心流程可用。
- 必须建立插画与图标系统，五个工作空间可以具有局部视觉特色，但版式、组件、颜色和 Fin 统一。
- 动画仅服务于交互结果，支持键盘与 `prefers-reduced-motion`。

### A5. Fin 不是临时 SVG 圆球

唯一角色为 Fin：**奶油白柔软身体、青绿罗盘叶冠、湖蓝短鳍翼、深青眼睛、阳光黄色罗盘吊坠、淡珊瑚腮红**；在小尺寸必须有辨识度，整体有体积感、动作感、亲和力和一致性。不是 V3 的渐变水滴，也不是儿童向夸张玩偶。

先提供**角色设定图、正/3⁄4侧/背三视、五种表情、五种动作、32/64/192px 尺寸验证，以及桌面/手机 Hero 中的实际组合效果**，供用户验收。

真实互动：点击或键盘聚焦 Fin → 小抽屉：`问 Fin 一个问题 / 看看我的发现 / 让 Fin 安静一会儿`；思考、好奇、开心、陪伴、休息五种状态；针对真实保存实验、完成专题、理解概念等事件轻量反馈。**不引入金币、XP、扣分、惩罚式签到，不随机伪造成就**。

### A6. 真实功能要求与内容风险

- 后端算式负责财务计算；前端不可伪造结果。标明假设收益率、复利口径、费用、期限和不确定性。编写单元测试验证 0% 收益、边界输入、还款费率、不同现金流时间点。
- AI 仅辅助解释；绝不代替确定性的数学内核。精选编辑资料 / 外部真实模型 / Demo 三种能力边界必须清楚。粘贴用户提供的文章不能声称已核实或伪造引用。
- 阅读、测验、实验和保存数据须具备用户归属校验与持久化。刷新可恢复，切换用户不串数据。路线与复习的已存在后端能力可保留，但应服务于真正的知识体验。
- Notebook 的保存值要可追溯：编辑文章 ID / 来源、实际参数、计算版本与公式口径、完成时间；再次打开可重放或明确历史版本差异。
- 五个专题及入口不能全部只导向聊天机器人。通过可实际触达的页面、图解、计算器和记录形成闭环。
- 不提供荐股、保证收益、资产交易或虚假投资建议。

### A7. Git 与安全，切记用户要求“覆盖 V3”

- 只修改 `v3`，不命名为 V4，不更改 `main`、`v2`，不 SSH、不部署腾讯云、不碰旧站和 DNS/ICP。
- **先检查** `v3` 分支是否仍存在（用户之前要求删除，不能假定已删除）、当前目录 Git 状态和是否存在未提交用户修改。
- 如果 `v3` 仍存在，以其为开发分支，保留/迁移有价值的业务代码，允许完全替换失败的前端。通过正常 commit 和普通 push 更新远端 `v3`，**绝不使用 `force push`、`reset --hard`、删库或直接覆盖用户文件**。
- 如果 `v3` 已被删除，但本地有工作树/压缩包，先诊断并报告可恢复范围；可从保留的 `v2` 建新的 `v3` 正常分支，经过安全确认后选择性移植过去已经验证的业务服务。**不要擅自复原用户否决的 V3 前端，也不要冒险强制推送**。
- 测试凭据仅本地 Demo，绝不提交环境变量、Secret、SQLite 中真实个人数据、第三方私有资料。

# FinPilot Redesign｜产品与视觉设计冻结稿（设计阶段收尾）

> 状态：设计方案冻结，未授权开发或创建新版本。V3 已被用户否决；是否已实际删除远程分支和本地工作区，须由 Codex 核实，不可假定已经删除。main/V1 与 v2/V2 作为历史参考保留。

## 1. 一句话定义与产品承诺

**FinPilot：看懂金融，形成自己的判断。**

帮助金融初学者把现实金融信息看明白、把与自己有关的数字算清楚、把容易混淆的概念真正弄懂。

核心旅程：**提出真实问题 → 选择合适的探索空间 → 动手操作 → 得到有依据的结果 → 保存与继续**。不以“功能数量、数据库表数、测试数”代替产品价值。

三大工作空间：
- **金融解读室 Decoder**：精选来源或用户提供信息 → 事实/解释/不确定性分层 → 关键概念与互动图 → 原始来源 → 保存发现；自由粘贴模式必须标明未核实，Demo 不冒充通用 AI。
- **Money Lab 财务实验室**：储蓄目标、复利、通胀购买力、贷款成本、预算情景等 → 用户参数 → 权威确定性计算 → 多方案比较与解释 → Money Receipt → Notebook；不提供具体投资指令。
- **Concept Studio 概念工作室**：一个真实困惑 → 直观关系图/动画 → 生活例子 → 一次小判断 → 针对性反馈 → 复习；不把答错一次当成稳定误解。

支持层：Discover 精选内容与专题、AI Copilot 上下文辅助、My World 发现手册/知识收藏/学习记忆、Fin 轻量伙伴。

## 2. 视觉基调（最终推荐）

**Daylight Studio 晴日编辑室 75% + Little Discovery World 微光探索 25%**。关键词：明亮、清新、丰富、精致、可探索、可靠。设计不等于空白；图表、插画、内容本身形成视觉丰富度。保留温暖、趣味，但不儿童化、不炒股终端化。

颜色参考：暖浅背景 `#F6F9F5`，内容白 `#FFFFFF`，深文字 `#243D40`，主青绿 `#267B78`，湖蓝 `#79BDCC`，阳光黄 `#F1C467`，珊瑚粉 `#EFA79B`。主色用于交互、次色用于图表/栏目、黄用于 Fin 和发现感、珊瑚仅少量提示。不得把所有模块涂成彩虹。

中文：现代无衬线（思源黑体/Noto Sans SC 或同等许可清晰字体），英文/数字 Inter 或匹配无衬线；**不再混用大幅 Georgia 衬线标题和极小全大写英文**。桌面 H1 46–54px / 650–700，H2 26–30px / 600–700，正文 16–17px / 400–500，辅助 13–14px；读者正文 17–18px，行高 1.7–1.8；正文可读对比度至少 WCAG AA 4.5:1，较大标题至少 3:1。

最大内容宽度 1240–1280px，阅读区 720–780px；间距系统 8/12/16/24/32/48/64；圆角主要 16–22px；用非对称、错落有序的杂志式排版代替一整排同尺寸卡片。

动效：普通交互 150–250ms，重要反馈 450–800ms，背景轻呼吸 6–12s。避免滚动视差、密集粒子、夸张弹跳；支持 `prefers-reduced-motion`。

## 3. 导航定稿

桌面顶栏（高度 68–76px）：左 FinPilot logo / 中 **首页、发现、财务工具、学概念、我的世界** / 右 全局搜索、**问 Fin**、用户入口。

- **首页**：解释品牌 + 问题入口 + 当下值得探索的内容。
- **发现**：专题精选、可信来源资讯、金融解读室入口（Decoder 是内容详情/工作区，不独占一级导航）。
- **财务工具**：Money Lab 工具目录与具体计算器。
- **学概念**：Concept Studio、知识主题与学习路线。
- **我的世界**：Notebook、保存的解读/计算/课程、Fin 的角落和必要学习进展。
- **AI Copilot**：通过“问 Fin”、正文选区和上下文入口打开同一 AI 服务；它可有独立完整页，但不强制占顶栏宽度。
- **FinTalk**：如保留，入口应出现在相关主题/专题或发现页的讨论区，不独占首要导航；保留现有数据和功能，不做伪造活跃社区。

手机导航：顶部 logo + 搜索/Fin；底部 4 个主入口“首页 / 发现 / 工具 / 我的”，Concept Studio 从首页、发现、搜索与“学概念”快捷入口进入；单手可操作。不能把桌面 7 栏压成小字。

## 4. Home 最终桌面版面

**首屏目标：宽 1440px、高约 900px 的常见视窗，在无需滚动或稍微滚动即可看到“品牌、主问题入口、三大任务”**；不把首屏做成巨大空白展厅。

1. **顶栏（约 72px）**：logo、5 导航、搜索、问 Fin、用户。
2. **主 Hero（建议内容高 390–460px）**：左侧约 54% 文字与互动；右侧约 46% 品牌“金融探索桌”高质量插画。左侧：小幅品牌提示、“看懂金融，形成自己的判断。”两行强字重标题、一段不超过 2 行的具体价值说明，**一个醒目的问题输入框**（示例问题可轮播，但不应花哨）；下方 3 个可点击示例问题：新闻解读、存钱计算、ETF 概念。右侧：Fin 站在/飞在真实内容物件中（打开的学习手册、简洁增长图、信息剪报、计算器、活泼的小植物），用插画讲清三种能力；不得绘制只有透明细线的空星图。搜索/提问是主行动，不再重复放同等级巨大“开始探索”按钮。
3. **三大任务入口（首屏底部可见）**：三块外观各异但统一的入口：① 看懂信息（剪报与高亮句），② 动手计算（真实趋势线小预览），③ 学个概念（可视化对比）。每块均包含“具体例子 + 明确可操作行为”，不是泛泛介绍功能。鼠标悬停出现轻量内容变化；按钮导航必须到实际页面。
4. **编辑精选（第二屏开头）**：一张横向大专题 + 两张小专题，展示“主题 / 为什么值得看 / 估计用时 / 可信来源类型”；静态资料不冒充实时新闻。首批 5 个高质量专题：大学生第一份预算；存钱与购买力；从降息理解债券；ETF 究竟是什么；贷款到底要还多少钱。
5. **试试手边的工具**：一个可以在首页直接修改一项参数、即时看到变化的 Mini Lab + 两个工具快捷入口；算式与数字必须真实。
6. **一分钟弄懂**：一张精致概念对比图解 + 一个 1 题微练习预览；不要只有“阅读全文”。
7. **继续我的探索（条件显示）**：有真实历史才展示上次阅读、未完成实验/路线、到期复习；新用户展示“从这里开始”的精选示例，绝不出现 0% 的空仪表盘。
8. **Fin 的小角落（靠页面后段）**：一个小巧可爱的互动与收藏预览，**不盖住主功能、不抢过首页内容**。
9. 页尾：教育用途声明、方法与数据说明、关于、隐私。

### Home 文字定稿示例
- 标题：**看懂金融，形成自己的判断。**
- 副标题：**财经信息看得懂，生活里的数字算得清，抽象概念也能自己试一试。**
- 输入框提示：**今天有什么金融问题想弄明白？**
- 示例：**为什么降息后，债券价格不一定上涨？** / **每月存 500 元，两年后有多少？** / **ETF 和指数基金到底差在哪？**
- 三主入口：**看懂一件事 / 算清一个问题 / 弄懂一个概念**。

## 5. Home 手机版面

375/390/430px：顶部 logo/搜索/Fin，左侧标题最高两至三行，Fin 作为右上插画点缀（不挤压文字），提问框首屏可见；示例问题改为横向可滚动 chips；三主任务**纵向精致异形条目**，每个附带一个可见例子与小插画，非三列缩小；精选专题为一大一小可滑动；Mini Lab 移动端先展示参数和即时结果，深度控制折叠；底部四栏导航固定且无键盘遮挡。禁止空白海报占据全部手机首屏；不持续漂浮 Fin 遮住底部操作。

## 6. Fin 角色造型冻结

**命名：Fin**。定位是“温暖好奇、会飞的小小金融导航员”，是可信赖的陪伴者，不是幼儿园吉祥物、真实动物，也不是 V3 那颗极简渐变圆球。

**唯一可识别轮廓（必须在 32px 时也能辨识）**：偏椭圆、奶油白的柔软主体；顶部一枚小小青绿罗盘叶/船帆状冠；两侧一对短短、圆润、轻透的湖蓝-薄荷“鳍翼”；大但不占全脸的深青色眼睛，表情用眼形与眉/腮变化；胸前或腰侧有一枚精致、可拆解成小图标的阳光黄色罗盘吊坠；小短手和不显眼的脚，适合站在书本或图表边。轻浅描边与软阴影，避免油亮塑料玩偶感；轮廓不借用现有知名 IP。

色彩：主体暖白 `#FFFDF6`；薄荷 `#9DDCD0`；鳍翼湖蓝 `#7AC6D0`；轮廓深青 `#24585A`；罗盘黄色 `#F1C467`；腮红淡珊瑚 `#F2B7A6`。主体有足够明暗体积，不是一团发白的圆。

应用规格：Hero 插画中主体视觉约 160–220px 高（作为复杂场景的一部分）；内容页辅助 44–64px；紧凑触发器 28–36px；手机 Hero 88–116px；小尺寸保持眼睛、冠、鳍翼、吊坠四个识别点，不堆细节。

**资产清单必须先做出来并由用户人工验收**：一张角色比例与配色设定、正面/3⁄4 侧面/背面三视图、5 种标准表情、5 个常用动作、32/64/192px 渲染测试、浅色/彩色背景可读性测试。生产可采用统一 SVG/轻量动画资产，但不能随机拼接不一致的表情或临时 emoji 代替。

## 7. Fin 性格、状态与交互

性格：好奇、贴心、偶尔调皮、尊重用户、不说教；例“要不要换个数字试试？”“这里有个容易忽略的条件。”“这张结果我给你收好了。” 禁止“哇你太棒了！！”式过度赞美，也不以用户未登录/未学习制造愧疚。

五种核心情绪：
- **Calm 陪伴**：闲置微呼吸，坐在书边看着用户；
- **Curious 好奇**：轻歪头、眼睛上移，面对新问题/新概念；
- **Thinking 思考**：眨眼、罗盘轻摆，AI 正在处理任务时；
- **Bright 明亮**：眼睛弯起、双鳍轻抬，完成真实实验/学习成果后；
- **Resting 休息**：收起翅鳍、安静停驻，阅读专注模式或用户要求安静时。

五类动作：轻轻挥手、歪头、翻小卡片、递出 Money Receipt、把收藏贴进 Notebook。必须有 reduced-motion 的静态替代。

**主动交互**：点击/键盘聚焦 Fin 弹出**一个小抽屉**，有三个清楚选项：“问 Fin 一个问题”“看看我的发现”“让 Fin 安静一会儿”；鼠标轻触可短动作，但不依赖 hover 完成关键功能。Fin 与 AI Copilot 同一服务和会话，不创造第二个伪 AI。

**事件触发**：
- 第一次提出并成功解决真实问题：Fin 在页面边缘递出“你的第一张发现卡”；
- Money Lab 保存计算：Fin 递出该次真实数值的实验小票；
- Concept Studio 完成有效练习：Fin 把概念卡放进 Notebook；
- Review 多次正确证明此前混淆点已理解：Fin 温和提示“这两个概念现在更清楚了”；
- 返回用户未完成内容：Fin 指向上次保留的进度；
- 专注阅读或用户选择安静：Fin 自动缩小/静止。

频率：重大动画一个会话最多一次；其他反馈应小且不阻碍内容；绝无硬性签到、金币、XP、饥饿、扣分；情绪和收藏不可凭随机浏览伪造，首次成果与收藏去重且可持续查看。用户可关闭动画/声音/陪伴入口。

## 8. My World / Notebook 与 Fin 的去向

My World 首页是一本“持续积累的金融发现手册”，不是 24 张证据百分比卡。视觉可包含：保存的金融解读、Money Receipt、概念卡、最近想继续的问题、有限可视化的个人知识连线、Fin 小书架。Fin 的收藏来自真实操作结果，可点开对应原始解读、实验参数、题目和时间；没有记录时展示真实可做的起步入口。

## 9. 上线前必须存在的真实内容

五个精品专题都有可核查来源/编辑说明、清楚结构、足够内容、交互图解及完成路径。资讯日期真实；无法实时更新的，标示历史/示例。计算工具必须与文档公开的公式、现金流时间点和费率口径一致；保存后可以恢复输入。Demo AI 能力与 External AI 能力清楚区分。不提供交易、荐股、收益承诺或投资组合执行。

## 10. 页面行为及无障碍验收

- 首页每个显著点击区都能进入真实存在的页面或有用的操作；输入问题能合理分流三工作区，不确定时让用户选目标，不假装 AI 已理解全部。
- 财务工具有实时真实计算、至少两种情景对照、关键假设解释与恢复保存值；移动端不因键盘覆盖内容。
- Decoder 有来源、事实/解读/不确定性区分、术语、可见的图解，粘贴资料不伪造已核验状态。
- Concept Studio 至少一套完整可操作图解及即时反馈；题目错误与复习记录是同一用户的真实状态。
- Fin 点击/键盘访问可用，按钮有标签、抽屉焦点可控、Esc 可关闭；阅读专注模式不会被打扰；支持 reduced motion。
- 典型 1440x900 首屏看得到产品能做什么，375/390/430px 触屏可完整运行核心体验。
- 每屏有清晰视觉中心，不能存在半屏淡线、极小灰字、纯装饰性的空内容、同样的矩形卡片墙。
- 必须有真实截图供用户亲自批准；不能以测试全过宣告视觉验收通过。

## 11. 冻结流程与当前边界

**现在只完成设计，不授权 Codex 写生产代码、建新分支、部署服务器或删除/重置任何未确认的数据。**

下一阶段须先交付：Home 桌面与手机版高保真、Money Lab/Decoder/Concept Studio 核心真实互动原型、Fin 角色设定与表情/动作表。**用户看过实图、用过互动原型、明确表示满意以后**才编写开发任务书，考虑是否建立下一版本分支。不要自动叫 V4。

最终一句设计准则：**第一眼好看，第一分钟有用，第一次保存有获得感，第七天还有理由回来。**
