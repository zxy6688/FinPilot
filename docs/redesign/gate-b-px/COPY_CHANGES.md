# 本轮文案前后对比

|位置|修改前表达/问题|修改后|
|---|---|---|
|贷款主结果|全部支付 total_paid 包含期初扣费，易误读为每期还款合计|还款期内总共要支付；今天实际到账；额外借款成本（利息＋全部费用）|
|贷款有效年成本|术语与 APR 边界抢占主结果|按模型现金流计算的年化成本；口径进入方法说明|
|保存实验|Money Receipt 等内部称谓|实验小票；保存后能恢复参数再比较|
|比较|固定 A，含义不够明确|保留此方案为 A；先保留方案 A，再改参数比较 B|
|首页|自由提问容易被理解成直接回答|搜索站内专题和工具；这里不会直接生成答案；相关内容不一定解答具体问题|
|专题练习|即时正确反馈容易被理解为进入复习|即时练习 · 不计入复习|
|概念正式提交|点击/答对与掌握含义混合|后端成功才显示加入账户复习；答对一次不代表已掌握|
|阅读保存|hash 章节与实际阅读位置混淆|阅读位置自动记住；笔记与实验需主动保存|
|Demo|保存到我的账户可能暗示私密|共享演示账户，所有使用者可见；不要输入私人信息，使用独立账户|
|Discover|精选内容容易被误当每日新闻|首批精选专题，标注更新日；不是即时新闻服务|
