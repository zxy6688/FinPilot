# FinPilot · Fin 3D 电子宠物：产品设计 v1.0

> 状态：待评审的下一阶段设计；不修改正在开发的 Gate B–R；拟在 C3–C5 与 My World 完成后实现。依据：Gate B–K 项目源码（Fin.tsx、FinChat.tsx、Layout.tsx、backend/app/services/v3/living.py、角色设计页）；本机最新 V3 仍需 Codex 集成前核对。

## 0. 设计决定

- **定位**：FinPilot 五个页面之外的常驻 3D 伴侣。网页中跨路由持续出现，不与 Home、Money Lab、Discover、Concept Studio、My World 抢主任务。
- **人格**：好奇、贴心、有一点小幽默，善于安静陪着，承认不知道；有个性但不装成人类或治疗师。
- **原则**：会动、有反应、带来陪伴感；不打断填写，不强迫每天登录，不用悲伤或惩罚驱动留存。
- **形象**：从既有暖白身体/薄荷鳍翼/深绿叶冠/琥珀罗盘演化为真实 3D 模型，而非换一只毫无关联的宠物。
- **实现路径**：可操作的 Web 3D 先行；未来如需像 Codex 桌面宠物跨所有软件悬浮，再开发 Tauri/Electron 桌面外壳。这两类悬浮不是同一种能力。
- **能力边界**：默认互动由确定性脚本驱动、无 API 调用；用户显式选择「问 Fin」后才进入现有 FinChat（保持 Demo 标识与金融教育限制）。

## 1. 三种形象方向及推荐

### A. 小罗盘精灵（推荐）
- 轮廓：圆润的梨形暖白躯体，头大身短，略微前倾；有极短足、两个可张合的半透明薄荷翼，胸前嵌一枚可轻微转动的琥珀罗盘。
- 识别点：深绿小叶冠像呆毛，随呼吸轻摆；眼球有真实观察方向；面颊浮出短暂暖粉色，不一直涂红。
- 材质：磨砂软瓷 + 轻绒质感；阴影柔和；不使用过度透明、镜面金属或塑料高光。
- 美术关键词：暖白、薄荷、手办级别、软体弹性、眼神有戏、像有重量的小生物。
- 角色特色：罗盘指针会随着专注、好奇和喜悦发生变化，但永远不用于模拟真实金融预测或运势。

### B. 灯火精灵（可作为皮肤）
- 更柔软，带低亮度的温暖呼吸光，适合夜间安静陪伴；需控制发光度、降低性能成本。

### C. 旅行家 Fin（可作为衣装系列）
- 不更换本体：增加小围巾、纸飞机、零钱包或旅行斗篷；适合节日/成果纪念。

**明确不做**：拟人类少女/男孩、带脸的手机机器人、真实动物复制、过度卡通头大身小导致难以做动作的软胶球。

## 2. 3D 角色设计细则

- 基本体态：圆润但有骨骼层级，重心在下腹，身体能轻微压缩与回弹。
- 角色骨骼：root / body / head / leaf-stem / leftWing / rightWing / leftArm / rightArm / leftFoot / rightFoot / compass / eyes / eyelids（具体命名可根据建模调整）。
- 脸部：眨眼（含不对称眨眼）、目光移动、眼形弯曲、嘴角、鼓腮、疑惑歪头、微困倦。
- 物理感：起跳前先下蹲，落地压缩再回弹；被摸时靠向手指；被拖拽时脚部有惯性；停下后缓慢恢复。
- 鼠标追随：只转眼睛和头部，小角度、有迟滞；不用整个身体持续追踪以免分散注意力。
- 动作单：呼吸、眨眼、左右张望、歪头、轻走、快步、轻跳、转圈、坐下、趴下、伸懒腰、揉眼、打盹、蜷睡、醒来、挥手、鼓掌、捧小卡、翻书、递出小票、举小灯、抱抱自己、靠近、被摸缩颈、踩空小失误、兴奋小跳、害羞退半步、抱星星、进入口袋/缩小、换装；至少提供 18 个首版可用动作，完整规划 28–32 个。
- 视觉情绪：平静、好奇、专注、开心、害羞、困倦、担心、委屈、骄傲、疑惑；其中“担心”只用于清楚的应用故障或用户主动心情表达，不自动判断用户心理状态。
- 服饰配件：基础罗盘、围巾、叶子发饰、迷你眼镜、星星小包、软毯、纸船、小灯、小书。默认不用复杂商城和随机抽卡机制。

## 3. 立体常驻交互与布局

- 在全站根布局的 Outlet 之外挂载 PetProvider + PetOverlay：路由变化不卸载角色，动画状态和最近互动得以延续。
- 桌面默认位置右下，角色占位约 100–150 CSS px，透明背景，点击/拖动区域仅在角色可见范围；绝不盖住输入框、提交按钮、重要数值。
- 手机默认约 52–68 CSS px，优先停靠在顶部或侧边非主要操作区；遇到软键盘、计算器浮层、底部导航时自动缩成小圆点或暂时收起。
- 用户可拖动到四角；刷新和跨页保留停靠位置；提供「隐藏」「安静陪伴」「减少动画」「关闭声音」「重置位置」。支持不显示 Fin 的极简模式。
- 触摸反馈：轻点挥手；长按轻摸；左右拖动移动位置；重复点击使用冷却，不造成狂闪或无限弹泡泡。
- 展开面板为轻量抽屉（不是整页跳转）：`陪我一会儿`、`现在的心情`、`一起专注`、`问 Fin`、`我的 Fin`、`设置`。面板打开时才展示功能；默认界面只见角色。
- **网页范围限制**：网页能够跨 FinPilot 路由常驻，不能在用户关闭网站后浮在 Windows 其他程序上方。跨应用悬浮需要单独桌面外壳并经过用户授权。

## 4. 情绪陪伴：用户主动选择，Fin 适度回应

用户自行点选：`挺好的`、`有点累`、`烦躁`、`没精神`、`想有人陪`、`说不上来`，或者不选择。

回应由三部分组成：
1. 身体动作（靠近、坐下、把小毯子拿过来、默默陪在旁边）；
2. 0–2 句自然的话，允许只有动作没有语言；
3. 可选、不会打断主页面的小动作，例如 `和 Fin 安静坐 1 分钟`、`一起伸个懒腰`、`摸摸它`、`把此刻写成一句话`、`继续做事`。

- “我在这里”不应变成“你只有我”。不暗示 Fin 具有真实依恋、痛苦或需要被照料的生理需求。
- 不推断用户收入、贷款、错误答案等意味着他们情绪低落；财务数据无需进入宠物脚本引擎。
- 心情记录默认当前会话有效；用户主动选择“保存今天的心情”才存入个人记录。
- 面对高度危险的自我伤害表达，转由经过审核的专门安全响应处理；不能靠可爱台词硬安慰。

## 5. 学习相关触发器（不重做学习功能）

- `QUIZ_WRONG`：失误时挠头或在一旁抱书，提示查看题目条件，不直接泄露答案；1 次/题为上限。
- `QUIZ_CORRECT`：点头或举小星星，连续多题才小幅庆祝，避免频繁强刺激。
- `EXPERIMENT_COMPARE`：两个结果对照时眼睛跟随数值变化，偶尔说“差别在这里”，保持解释具体。
- `SAVE_SUCCESS`：Fin 接住小票并收进迷你包；必须由后端确认成功后触发。
- `SAVE_ERROR`：递回小票、提供重新保存，不说已经记住。
- `LESSON_FINISHED`：轻跳庆祝；与真实完成记录绑定。
- `REVIEW_DUE`：在用户允许提醒的条件下展示数量；不说“拖欠”“又没复习”。
- `TOOLS_CALCULATION`：做完预算、储蓄、贷款计算后，不评价金额/得失，也不提供个性化投资建议。

## 6. 不学习时也能做什么

- 轻摸、捧起、玩纸船、踢软球、滚小叶子、转罗盘、和 Fin 玩十秒“你看哪里”、一键切换姿势。
- 安静坐一会儿：提供无任务的陪伴场景，没有倒计时压力、没有奖励扣分。
- 1 分钟休息：可选温柔呼吸光、眨眼或喝水提醒，只有用户要求才开启。
- 个性化小窝：改变靠垫、窗景、灯光、围巾和小物件；角色仍常驻其他页面，小窝是抽屉内独立布景。
- 收集“生活小片段”：用户主动保存的一句话、一次完成的课程、一张真实的实验小票。无强迫打卡和连续签到惩罚。
- 季节变化：小雨窗景、冬季围巾、夜晚小灯、书桌秋叶；提供开关，不依据不准确的定位推天气。
- 轻量随机事件：Fin 偷偷打呵欠、小叶子歪了、发现小纸飞机；仅在用户空闲且未操作关键控件时发生，且每日次数有限。

## 7. 六类陪伴模式

| 模式 | 角色举动 | 开启与退出 |
|---|---|---|
| 正常陪伴 | 呼吸、眨眼、偶尔小动作 | 默认；可随时隐藏 |
| 静陪 | 坐下，少动作，不主动说话 | 用户自选，保留到关闭 |
| 陪学 | 温和专注动画、可选计时 | 用户主动开始、停止 |
| 心情模式 | 依据用户自述心情回应 | 只针对用户当前选择 |
| 轻玩 | 摸摸、互动玩具和换装 | 用户主动打开 |
| 问 Fin | 调用现有 FinChat | 用户明确点击，标记 AI/Demo 边界 |

## 8. 脚本系统

建议采用 JSON/TS 的可审计规则库：每条脚本包含 id、触发事件、必要条件、角色动作、文字、声音标识、优先级、冷却时间、每天上限、互斥组、审阅版本。详见同包 `fin_scripts_v1.json`。脚本库初步应覆盖：问候、归来、浏览、输入、完成、错误、保存、未保存、心情、安静、休息、游戏、偶然事件、季节和节日、夜晚、低性能降级与退出。

使用**有状态的导演系统**，而不是“每次事件随机一条台词”：
1. 收到经过授权的事件 → 检查模式、路由和无障碍设置 → 应用频率限制；
2. 按事件优先级选择反应 → 播放短动作 → 视条件显示一句台词；
3. 播放结束自然回到空闲动作；
4. 永远允许用户关闭宠物、关闭文字和关闭声音。

建议主动气泡默认每会话不超过 2 次，每日不超过 5 次，至少间隔 15–20 分钟，错误/成功等重要事件可用无文字小动作表达。数值只是初版 UX 参数，需由真实使用测试调整。

## 9. 技术方案（对现有 FinPilot 侵入最小）

- React 19 + React Three Fiber 9 + Three.js；版本在真实最新 V3 上检查锁文件后再确认。R3F 模型与应用状态隔离。
- Blender 制作 rigged Fin → GLB/glTF；优化网格、纹理与动画，按需加载 3D 库与模型；手机/低端设备用 2D sprites 或静态 FinArt 降级。旧角色插画仍用于文章等静态场景。
- 3D 资源建议首屏预算：压缩模型、动作和纹理总量目标 1–3MB（工程目标而非保证值），实际按弱网端实测；Idle 降帧，页面隐藏暂停渲染。
- 新模块建议：`fin-pet/PetProvider.tsx`, `PetOverlay.tsx`, `FinModel.tsx`, `PetDirector.ts`, `PetScripts.ts`, `PetStore.ts`, `PetSettings.tsx`, `PetRoom.tsx`, `PetAudio.ts`。
- 状态分级：`PetVisualState`（动作/位置/表情）、`PetPrefs`（显隐/静音/大小/衣装）、`PetEvent`（只读应用事件）、`PetMemory`（用户明确许可的记录）。
- 事件由金融计算器、笔记、学习路由在真实状态变化后发出；严禁宠物猜 DOM 文本或读取用户所有输入。
- 登录用户：只同步允许的偏好、衣装、主动保存的记忆；访客存在浏览器本地。退出时清理账号相关内存状态，避免串号。
- 优先本地运行脚本，无需 AI token；打开现有 FinChat 才使用后端 AI/Demo。2GB 香港云服务器负责传文件和业务接口，3D 渲染主要使用访问者设备的图形资源。

## 10. 安全、隐私和节制

- 无广告诱导、情绪内疚提示、悲伤值下降、强制喂养、连续签到处罚，不允许宠物对用户财务状况做价值判断。
- 尊重 `prefers-reduced-motion`；提供暂停/隐藏动效开关、无障碍替代文本和键盘操作，参考 W3C WCAG 2.2 2.2.2。
- 音效默认关闭；在首次用户明确启用后播放。夜间安静模式以用户本地时间和本人设置为准。
- 关闭宠物后不给“它会难过”的弹窗；它不应成为无法退出的入口或情绪绑定机制。
- 用户主动保存的心情和日志应具有查看、删除与导出的途径。

## 11. 开发顺序与验收

**P0：模型与活体演示**：完成一只真正可转身的低多边形 3D Fin；至少呼吸、眼神、眨眼、走动、跳跃、坐下、打盹、挥手、被摸动作；在 1440/390 真机浏览器展示，不先做复杂 AI。

**P1：网站常驻**：根 Layout 级悬浮、可拖动、可隐藏、不会遮挡操作；跨五个主页面/刷新保持状态；键盘和减少动画可用。

**P2：导演与脚本**：引入完整脚本库、冷却、优先级及跨事件转场；真实保存/答题事件；至少完成 30 条经过实测的独特反应，后续扩充为 80–100 条。

**P3：陪伴能力**：六种心情按钮、静陪、短休息、轻玩、场景化小窝、装扮与非强制个人纪念。

**P4：可选 AI 与上线验收**：沿用 FinChat，保证无密钥时标记 Demo；账户隔离、手机软键盘、加载性能、低端机降级、无障碍、文案审查、用户数据备份。

**硬性验收**：角色看起来是三维实体而非把旧 PNG 加漂浮动画；转身能看到真实侧面/背面，翼与叶冠可独立动；交互由真实事件驱动；无打断、无越界遮挡、可完全关闭；没有第三方 API 时仍然可互动；FinPilot 原有金融逻辑、课程记录和导航不受影响。
