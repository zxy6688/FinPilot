# FinPilot V2 · Product

V2 将 V1 的内容与工具连接成以用户为中心的金融理解工作台。问题从“这里有什么”转向“我接触了什么、哪里仍有疑问、下一步为什么值得学”。内容规模、实验公式和技术栈保持 V1 基础。

## 五项核心能力

| 能力                   | 实际行为                                                                                                  | 数据不足时                                                                |
| ---------------------- | --------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| My FinPilot            | 接续未完成课程；显示最新仍错的题、证据较少的主题；沿真实关系推荐 1–3 个下一主题；关联现实资料、实验与路线 | 明确标记 Money Basics、新手 Lab 入口；不制造个人推荐理由                  |
| Understanding Map      | Profile 展示五条学习路径领域、24 个主题的四种状态、证据分项、待复习主题与近期活动                         | 显示未探索和引导，不显示伪造能力                                          |
| Learning Routes        | 从有证据的主题到所选目标，展示 Known / Next / Target、每步真实关系、课程与可用实验                        | 优先基础主题；无有向路线时明确标为 Connection Route；无连接时直接进入目标 |
| Contextual AI          | 课程段落、主题、关系、真实资料、实验及路线共用现有 AI Provider；支持解释、例子、连接、自测和后续动作      | 无 Key 使用明确标识的 Demo；请求失败显示错误与重试，外部调用失败标记回退  |
| Real World Connections | Discover 在已有真实来源目录中说明“为什么与你有关”、涉及主题、已有证据与待探索部分                         | 不展示伪造的个性化资料区，仍能浏览完整目录                                |

原知识罗盘保留。Learn 增加目标选择器，Topic、Profile 和 Search 都可进入路线。收藏路线目标复用 Topic 收藏；Home 可再次进入并依据最新证据重算，不保存僵化路线副本。

## 用户旅程

首次访问 → Money Basics / Topic → 阅读段落并使用 Contextual AI → 自测 → 查看理解地图 → 选择目标路线 → 理解带来源的现实资料 → 修改 Lab 参数 → 比较观察、解释与边界 → FinTalk 主题讨论 → Home 继续。

完成课程、自测作答、保存实验、浏览和收藏使用现有持久化流程。新用户注册不会获得体验账户的记录。只浏览课程会记录主主题接触，不被当成完课；继续学习依据实际作答、收藏、完课路径及近期主题推断。

## 理解证据与反馈

- 四状态：未探索、正在理解、逐步建立连接、已有较充分学习证据。
- Learning Evidence 是内容覆盖和站内行为的汇总，不是金融能力、投资水平或认知诊断。
- 默认权重为完课 40%、自测 35%、实验 15%、接触/收藏 10%；没有某类内容时移除该项并归一化。具体算法见 [架构文档](V2_ARCHITECTURE.md)。
- 自测以每题最新一次作答计算；答对可以解除该题的待复习状态。尚未解决题目的历史错误次数用于解释重复错误。
- 界面同时提供状态文字、颜色和可展开分项，避免只有颜色或只有总分。

## 轻量扩展

八个 Lab 各有与原主题一致的情景、观察问题和反思入口。仍调用原公式，AI 解释由后端重新计算当前输入与默认输入的结果，不接受客户端伪造结果。FinTalk 保留原讨论能力，突出 Related Topics 回链。

课程采用段落级 AI 按钮，而非依赖不稳定的浏览器文字选区；发送片段最多 1,200 字符。弹窗具有来源、动作和真实 Provider 状态，支持 Esc、焦点返回及追问。完整 Copilot 可打开已保存会话，追问保留原片段或实验参数。

按根目录 README 完成 Setup / Start。体验账户仍为 `demo@finpilot.app` / `demo123456`。如需截图中的明确样例学习状态，在 V2 根目录运行：

```powershell
. .\scripts\Environment.ps1
.\.venv\Scripts\python.exe -X utf8 scripts\prepare-v2-demo.py
```

## 边界

无新增表、无迁移、无随机推荐、无实时新闻抓取、无向量数据库或第二套 AI 系统。没有路线、资料映射或关联实验时如实显示缺失。Demo 是基于目录的解释模板，不能像外部模型一样自由理解所有追问。外部模型适配已测试模拟成功及失败回退，未使用真实 Key 联机验收。

**NOT DEPLOYED**：本轮不运行部署脚本，不修改服务器、旧站、正式域名或安全组。仓库 `deploy/` 保留的是 V1 并行预览资产，不应作为 V2 发布指令。
