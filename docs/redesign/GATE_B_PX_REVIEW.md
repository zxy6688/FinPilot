## 保存、隐私与兼容性

独立账户使用后端 SQLite，记录读取、改名、删除均验证归属。访客只保存在当前浏览器；共享 Demo 仍是共享身份，仅供本地教学体验，禁止私人输入。公开服务默认关闭共享 Demo；本轮未修改服务器。数据库无破坏性迁移；重命名写入既有 snapshot JSON 的 user_title，原快照内容保留。旧 total_paid 保留兼容，新增 repayment_total/upfront_deducted。
