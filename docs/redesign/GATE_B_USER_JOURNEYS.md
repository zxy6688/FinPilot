# Gate B 用户旅程（B0契约与最终实测）

## 1. 大学生预算
首页预算精选 → 预算专题：小林每月 2500 元的明确教学假设 → 区分固定/弹性与储备 → 修改收入和支出 → 加一次维修支出 → 环图、结余与目标缺口同步变化 → 理解储备不是已经消费的钱 → 固定 A、调整 B → 登录保存预算实验与自己的一句话 → My World 按实验筛选 → 新登录会话恢复参数、情景和原结果。零收入与超支给出金额解释，不显示无限比例。

## 2. 购买力
Discover 钱与生活 → 保留六节原购买力长专题 → 来源可点开且与假设区分 → 修改通胀、年限、名义增长 → 名义/实际曲线与实际收益口径 → 全工具携带参数 → 返回原章节 → 答误区题并看针对性解释 → 保存带来源和实验的发现 → 手册恢复。首页模糊问题先给建议，不宣称智能解答。

## 3. 贷款
借贷成本专题 → 分清借款面额/净到账/总还款/现金流时间 → 切换等额本息、等额本金 → 加期初手续费与逐月费用 → A/B 比较每期压力、总成本与有效年成本 → 0 利率有费用仍有成本 → 保存完整现金流与假设 → 重新打开。拒绝无净到账与非有限输入，不输出伪 APR。

## 4. 降息与债券
Discover 市场资料 → 明确标注教学假设的政策链 → 政策利率不直接等同某债券市场收益率 → 调整市场收益率，固定票息与期限 → 价格反向曲线、期限敏感性 → 错题解释预期与信用风险 → 查看官方来源 → 保存输入与发现 → 返回同一情景。不虚构近期新闻/报价，不增加第六个财务工具目录。

## 5. ETF
首页/搜索 ETF → 二维分类矩阵 → 切换指数 ETF/主动 ETF/非交易所指数基金 → ETF 专题理解申赎/二级交易、折溢价、费用/跟踪误差 → 判断题先错后对 → 保存案例和解释、接现有复习 → My World 再开恢复同一案例与作答。访客明确仅本机，账户记录后端归属校验。

## 横向验收
每旅程桌面与 390px 浏览器实际操作；375/430/768 检查溢出、导航、表单与关键结果。登录/新会话恢复、重复保存、另一账户 404、网络失败不显示成功、重试保留参数。首页 MiniLab → 储蓄默认输入 → 固定 A/改变 B/恢复 A；复利口径与储蓄月度一致。课程、路线、复习与讨论旧 URL 冒烟。Fin 上下文与完整 Copilot 沿用同一会话；Demo 不认识的问题给能力边界。
