## P0: 视觉主问题（必须修）

### P0-1 Home 首屏：不仅三任务可见，而且美术质感必须接近参考图
当前实拍虽然比旧 V3 强，但右侧是朴素扁平 SVG 展台和小型 Fin，整体偏灰淡，仍缺少参考图的鲜活感、插画细节、层叠空间、品牌个性。请：
- 重绘或引入**独立制作的原创高质量插画资产**，形成丰富但不杂乱的 Fin 金融探索桌：角色主体、编辑资料、图表、书本、植物、空间环境、前中后层、局部颜色和光感；真实品牌资产而非 10 个几何图形。
- 保留首页真实表单/导航结构；参考图应启发**布局、美术品质和色彩密度**，禁止抄入假新闻与假数字。
- 1440×900 内首屏必须完整显示品牌主标题、可用提问入口与三任务。Hero 不得巨大空白；视觉资产不糊、不分辨率低，角色要有可辨识存在感。
- 右侧插画不是必须模仿浮空岛，但绝不能倒退为小型平面图标、抽象线框或通栏空白。

### P0-2 三个入口必须是不同的「真实内容预览」，不能只是三张浅色文字卡
当前 `.rd-task` 三张卡尺寸与结构几乎相同、内部没有实质图。参考图中每个入口下半部都有美术或功能预览。重新设计：
- Decoder：原创建议解读预览/重点事实卡，显示真实存在的专题/资料类型；
- Money Lab：用真实 API 结果生成**微型趋势图和金额**，不能装饰性地画一条不对应计算的假图；
- Concept Studio：ETF / 指数基金两轴小图预览，点击可进入真实互动；
- 卡片信息密度、图文比例、模块形态要明显有区别，且整体统一。

### P0-3 Fin：独立角色设计升级
当前 SVG 三视图中的正面和 3/4 侧面差异极小，角色扁平且表情/动作变化轻微；虽有五套图，距离批准图里的「有生命力的独特品牌伙伴」尚有差距。
- 必须呈现真不同的前 / 3/4 侧 / 背角度：冠、鳍翼、眼睛/头部转向、身体体积和吊坠透视一致；不是把正面缩移一下。
- 五个表情应当**肉眼显著可辨**；五个动作必须具有不同的动作剪影/手部道具和明确的触发反馈。静态姿态与动画要明确区分，不得冒充完整动画。
- 需要真正精致的造型体积、轮廓与细节（允许高质量原创透明 PNG/WebP 配合 SVG/动画；不要坚持简单代码 SVG 低保真路线）。角色和 Hero 必须同一种插画语言。
- 首页可点击 Fin，交互有视觉反馈；要支持 reduced motion 与键盘。
- 如果当前工具链不足以创作与参考图同级的美术资产，请**明确报告需要高质量角色/场景原画素材的阻碍**，不要用粗糙图形声称验收达标。

### P0-4 手机不是桌面纵向摞三张巨大卡
390px 截图现在 Hero 后三块几乎等高的大卡连续堆叠，第三块在首屏之外很远；顶部 Logo 和末端 Fin 还重复。新方案：紧凑的手机 Hero + 辨识度高的 Fin/局部场景 + 明确搜索输入，随后 3 条相对紧凑但有差异化预览的任务入口；重要路径必须可见且好点。合理分配竖向空间，避免造成长屏「刷卡墙」。底部导航不遮挡内容。

### P0-5 保持一致的视觉密度，并提升内页的图形表现力
Money Lab 已有后端确定性计算，保留此逻辑；在参数图表旁加入更清楚的多情景分色、操作反馈和可理解结果（禁止装饰性假数据），参考图的仪表感而不是 plain admin 表单。Concept Studio 目前两块轴卡和五根静态柱形信息量不足；做成**可互动 2×2 分类矩阵/例子卡，点击可高亮对应交点**，解释 ETF 交易形式与指数策略的交叉（不能混淆两个维度）。Decoder 保留六节长文，改善来源证据模块/信息层次，示意图与事实图明确标注，增加视觉表现但不抄外部文章。

## P1: 功能真实问题（必须修）
