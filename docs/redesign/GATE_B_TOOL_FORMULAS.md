# Gate B：模型口径、边界与复算

所有默认数字均为教学假设，计算在 FastAPI 中执行；LLM 不参与数学。输入利率以百分数传入，公式中的 r 为小数。金额展示到分，不代表真实金融机构账单。

| 工具 / API | 公式与时间点 | 边界与局限 |
|---|---|---|
| 储蓄 `/api/v3/tools/savings` | 月末：Bₘ=Bₘ₋₁(1+i)+C；月初：Bₘ=(Bₘ₋₁+C)(1+i)。年名义 i=r/12；年有效 i=(1+r)^(1/12)−1。反求月存向上取整到分，确保达标。 | 1–600 月，0–30% 年利率；本金 0–1000 万，月存 0–10 万；零利率使用线性和。无税费/利率变化。 |
| 复利 `/api/v3/tools/compound` | 一次性本金 PV，名义 FV=PV(1+r/m)^(mt)；有效 FV=PV(1+r)^t。m=1/2/4/12；有效口径不重复计息。 | 0–60 年，利率 −50%–30%，本金 0–1000 万；0 年保持本金，负收益可下降。不含追加款。 |
| 购买力 `/api/v3/tools/inflation` | 名义 N=PV(1+g)^t；实际 R=N/(1+π)^t；实际年收益=(1+g)/(1+π)−1。 | 0–60 年，π=−20%–30%，g=−50%–30%；零本金/零年/通缩均有定义。不是通胀预测；个人消费篮子有差异。 |
| 贷款 `/api/v3/tools/loan` | 月名义 i=r/12；等额本息 A=Pi/[1−(1+i)^−n]，i=0 时 P/n；等额本金 P/n 加当期余额利息。净到账=P−期初费用，t=1..n 月支付本金+利息+月费用。解净到账=Σ支付ₜ/(1+j)^t；有效年成本=(1+j)^12−1。 | 面额100–1000万，1–600整月，名义0–60%，净到账≥0.01元。非监管 APR；不模拟日计息、提前还款、浮息、逾期、保险或不等间隔现金流。 |
| 预算 `/api/v3/tools/budget` | 支出 S=Σ项目金额；结余 I−S；留储备后可分配 I−S−R；消费超支=max(S−I,0)，计划缺口=max(S+R−I,0)。 | 零收入时支出比例为 null，保留金额；储备不是消费；一次性费用只计当月。≤30项，去首尾空格及大小写后名称不能重复。各金额0–1000万；未模拟到账时点。 |

## 贷款与舍入

贷款用 Decimal 迭代现金流，内部不按每期四舍五入。展示行与总计各自舍入到分，因此逐行相加可能有分位差异。总成本=利息+期初费用+n×月费用。`total_paid` 表示本金及全部利息费用的名义合计，已经包含期初扣费；不得再从净到账扣一次同样费用。

IRR 对正净到账和正月付款使用单调现值函数，先扩展上界再二分160次；显式检查无法包围根的情况。零利息零费用成本为0。费用很高时有效年成本可能极高，这是现金流模型结果，不是推荐产品。

## 债券：专题内嵌，不是第六套顶层工具

`POST /api/v3/experiments/bond`：年付固定票息，P=ΣC/(1+y)^t+F/(1+y)^n；修正久期=Σt·CFₜ/(1+y)^t÷P÷(1+y)。市场收益率是折现输入，央行政策利率不是。票息0–20%、市场收益率−5%–30%、整年期限1–30。曲线展示−5%–15%的固定区间，另给当前收益率±0.5个百分点的精确情景。无违约、赎回、税费、应计利息；久期仅为局部近似。

## 快照与兼容性

五工具保存原输入、原结果、固定A、模型版本；重新打开显示历史记录并独立重新计算。储蓄继续识别旧 `savings-monthly-v1` 快照，缺失 `basis` 的旧记录按年名义处理；新增有效口径由 inputs.basis 明确保存。其他版本：compound-v1、inflation-v1、budget-v1、loan-monthly-v1。模型输出不是外部事实。
